第一个公开版本：一个轻量的 Android 任务解锁闹钟 —— **答对题才能关掉**。

## 亮点

- **五类题型**：单选 / 多选 / 填空 / 计算（运行时随机生成，背不下来）/ 九宫格手势
- **内置 48 道中文题目**，可增删改，也能导出成 JSON 用文本编辑器批量整理后再导回
- **按一周任意星期几重复**；一次性闹钟响过自动停用
- **铃声自由**：系统铃声 / 本机音乐 / 任意音频文件（SAF），支持以记录起止区间的方式截取片段，不做音频转码
- **无网络、无账号、无广告、无统计**，R8 压缩后约 **1.3 MB**
- 117 个 JVM 单元测试；GitHub Actions 自动跑测试并构建

## 安装

下载下面的 **`app-release.apk`**，在手机上打开安装即可（首次会提示「禁止安装未知应用」，允许你用的文件管理器就行）。

- 支持 **Android 8.0（API 26）** 及以上
- 升级请**直接覆盖安装**，不要先卸载

> ### ⚠️ 国产 ROM 用户请先做一步设置
>
> 华为 / 荣耀 / 小米 / OPPO / vivo 默认会把「从最近任务划掉」当成**强行停止**，
> 而强行停止会让系统取消应用的全部闹钟 —— 表现就是划掉之后闹钟**完全不响，也没有通知**。
>
> **请先按 [后台放行指南](https://github.com/Xiaorenjing1096/task-alarm/blob/main/docs/oem-background-whitelist.md) 设置**，
> 否则这个应用在你的手机上不可靠。
>
> 不确定生效了没有？应用内置了「设置 → 响铃诊断记录」，
> 到点没响时看一眼记录就知道是「系统没唤醒应用」还是「应用侧真的有问题」。

## 已知限制

- **应用被强行停止后闹钟必定失效** —— 这是 Android 的设计，任何闹钟应用都一样，代码无法绕过
- **亮屏时答题界面不会自动弹出** —— 系统只在锁屏 / 息屏时自动拉起全屏通知；
  此时闹钟仍会响并弹出悬浮通知，点一下即可进入
- **铃声片段只在本应用内有效**，不会生成能被系统铃声设置选中的新文件
- 响铃时答题界面的返回键被拦截，但 Home 键和强行停止拦不住

## 权限说明

| 权限 | 用途 |
|---|---|
| `USE_EXACT_ALARM` | 精确闹钟，否则可能被系统推迟十几分钟 |
| `USE_FULL_SCREEN_INTENT` | 让答题界面能盖在锁屏上 |
| `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_MEDIA_PLAYBACK` | 响铃时持续播放 |
| `POST_NOTIFICATIONS` | 响铃提醒 |
| `VIBRATE` / `WAKE_LOCK` | 震动；响铃期间保持唤醒 |
| `RECEIVE_BOOT_COMPLETED` | 重启后重新排期 |
| `READ_MEDIA_AUDIO` | 从本机音乐里挑铃声（用系统文件选择器则不需要） |

**本应用不申请任何联网权限。**
