# 后台放行指南：让闹钟在「划掉应用」之后依然可靠

**国产 ROM（华为 / 小米 / OPPO / vivo）用户请务必读完本页。** 不设置的话，从最近任务划掉应用后闹钟不会响，
而且没有任何提示 —— 这是本项目最常见的失效原因，且模拟器完全测不出来。

## 一、为什么必须手动放行

Android 有一条硬规则：

> **一个被「强行停止」（Force stop）的应用，系统会取消它的全部闹钟，并且不再向它投递任何广播。**

要区分两种看起来一样、实际完全不同的情况：

| 情况 | 闹钟还在吗 | 说明 |
|---|---|---|
| 普通的进程回收（内存不足被杀） | **还在** ✅ | 到点会把进程重新唤醒，不影响响铃 |
| **强行停止**（Force stop） | **被系统取消** ❌ | 应用进入 stopped 状态，什么广播都收不到 |

问题在于：**国产 ROM 默认把「从最近任务划掉」当成强行停止。**

于是表现就是：

- 应用留在后台 → 闹钟正常响
- 把应用划掉 → **到点完全没反应，没有声音、没有通知**

**这一点无法用代码绕过。** 被强行停止的应用收不到广播，Android 没有提供任何 API 能改变它，
所以只能由你在系统设置里放行。

## 二、先确认是不是这个原因

本应用内置了响铃诊断记录：**设置 → 响铃诊断记录**。

复现一次「划掉应用 → 等闹钟到点」，然后打开应用查看：

| 你看到的 | 说明 |
|---|---|
| 只有 `已排期(精确) …`，**没有** `收到闹钟广播` | ✅ **就是这个原因**，按第三节放行 |
| 有 `收到闹钟广播`，但没有 `开始播放铃声` | 不是这个原因，请提 Issue 并附上记录 |
| `收到闹钟广播` / `已进入前台服务` / `开始播放铃声` 都有 | 闹钟是正常的 |

「到点了却没有任何记录」本身就是最有力的证据：它排除了整个应用侧的链路。

## 三、各品牌放行步骤

### 通用（所有 Android 都要做）

1. **通知权限**：设置 → 应用 → 任务闹钟 → 通知 → 允许
2. **锁屏通知**：同上页面 → 允许在锁屏上显示
3. **电池优化白名单**：设置 → 电池 → 电池优化 → 所有应用 → 任务闹钟 → **不优化**
4. **全屏通知**（Android 14+）：设置 → 应用 → 任务闹钟 → 特殊权限 → **全屏通知** → 允许

### 华为 / 荣耀（HarmonyOS / EMUI）

最关键的一档，不做的话划掉必定不响。

| # | 项 | 路径 |
|---|---|---|
| 1 | **允许自启动** | 设置 → 应用 → **应用启动管理** → 任务闹钟 → 关闭「自动管理」→ 改为 **手动管理** → **自启动 / 关联启动 / 后台活动** 三项**全部打开** |
| 2 | **受保护应用** | 打开 **手机管家** → 应用启动管理 → 任务闹钟 → 设为**受保护应用** |
| 3 | **省电策略** | 设置 → 电池 → 更多电池设置 → 任务闹钟 → **无限制** |
| 4 | **锁屏通知** | 设置 → 通知 → 任务闹钟 → 允许通知 + **锁屏通知** |

### 小米 / Redmi（HyperOS / MIUI）

| # | 项 | 路径 |
|---|---|---|
| 1 | 自启动 | 设置 → 应用 → 应用管理 → 任务闹钟 → **自启动** 打开 |
| 2 | 省电策略 | 同一页面 → **省电策略 → 无限制** |
| 3 | 后台弹出界面 | 同一页面 → **其他权限 → 后台弹出界面** 打开（不开的话答题界面可能弹不出来） |
| 4 | 锁定后台 | 最近任务里下拉任务卡片加锁 🔒 |

### OPPO / 一加 / realme（ColorOS）

| # | 项 | 路径 |
|---|---|---|
| 1 | 允许自启动 | 设置 → 应用 → 应用管理 → 任务闹钟 → **允许自动启动** |
| 2 | 允许后台运行 | 设置 → 电池 → 应用耗电管理 → 任务闹钟 → **允许后台运行** + **允许应用自启动** |
| 3 | 锁定后台 | 最近任务里点任务卡片右上角 → 加锁 |

### vivo / iQOO（OriginOS / Funtouch）

| # | 项 | 路径 |
|---|---|---|
| 1 | 自启动 | 设置 → 应用与权限 → 权限管理 → **自启动** → 任务闹钟 打开 |
| 2 | 后台高耗电 | 设置 → 电池 → 后台耗电管理 → 任务闹钟 → **允许后台高耗电** |

### 三星（One UI）

| # | 项 | 路径 |
|---|---|---|
| 1 | 移出休眠 | 设置 → 电池 → 后台使用限制 → **休眠应用** → 把任务闹钟移出 |
| 2 | 不受限制 | 设置 → 应用 → 任务闹钟 → 电池 → **不受限制** |

### 原生 Android / Pixel / 类原生

只需要上面的「通用」部分。原生系统**划掉应用不会取消闹钟**。

## 四、放行之后怎么验证

再做一次「**划掉应用** → 等闹钟到点」，然后打开应用看 **设置 → 响铃诊断记录**：

```
13:34:00  收到闹钟广播 id=31f21b20        ← 出现这一行就说明放行成功 🎉
13:34:00  响铃服务开始执行
13:34:00  已进入前台服务
13:34:00  开始播放铃声：content://settings/system/…
13:34:07  答题界面已打开
```

## 五、万一还是不行

1. **重新确认「电池优化」和「自启动」** —— 有些 ROM 在系统升级后会把这些设置重置
2. **打开一次应用** —— 应用会在启动时重新注册全部闹钟（自愈逻辑），可作为临时补救
3. 到 [Issues](https://github.com/Xiaorenjing1096/task-alarm/issues) 反馈，
   **附上「响铃诊断记录」的内容**（设置页可直接复制），那是最有用的信息

## 六、另一个无关但容易混淆的现象

**亮屏（正在用手机）时答题界面不会自动弹出。** 系统的全屏通知只在**锁屏或息屏**时才会被自动拉起；
亮屏时闹钟照样会响、也会弹悬浮通知，只是界面需要点一下通知才出现。

这是 Android 对后台启动界面的限制，不是本应用的问题，也无需放行设置。
